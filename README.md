# GuardIQ landing page

A responsive, single-file marketing website for the GuardIQ Smart Heater Safety Controller concept.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace `hello@guardiq.example` in `index.html` with your real team email.
- Add a real contact email and any verified social links.
- Only make claims about tested performance, certifications, regulatory compliance, or safety outcomes when you can substantiate them.
- The dashboard is illustrative only. The form opens an email draft; it does not store submissions or control hardware.

## Publish free with GitHub Pages
1. Create a GitHub repository, e.g. `guardiq-website`.
2. Upload `index.html` (and this README if desired) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to provide the public URL. Use that URL in your assignment form.
